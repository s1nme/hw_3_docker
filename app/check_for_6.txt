Выполним эти команды:

1) curl -fsS -w '\n' -X POST http://127.0.0.1:8080/increment
2) docker compose ps -q web
3) docker compose down
4) docker compose up -d
5) curl -fsS -w '\n' http://127.0.0.1:8080/
6) docker compose ps -q web


После выполнения 1 команды  "count": 1.
2 командой мы узнаем ID нашего контейнера, после чего двумя последующими командами пересоздаем контейнер. 
5 командой смотрим на count после пересоздания и он остался таким же.
6 команда показала другое ID, а значит контейнер был действительно пересоздан.
